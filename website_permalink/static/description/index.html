Website Permalink

Rename a page. Keep its URL.

Odoo builds the web address of a product, an eCommerce category or a blog post from its name. Rename it and the address changes with it, so every link to the old one (your newsletters, social posts, partner sites and Google) now points somewhere the page no longer lives.

Website Permalink keeps the URL when you rename a page that has been published. When you do want a new URL, Odoo asks first and leaves a 301 redirect behind.

How it works

  • Rename and keep the URL (the default). The title changes, the address stays put.
  • A question on every save. Saving a renamed page opens a dialog: keep the URL, or change it to match the new name with a 301 from the old one (pre-checked).
  • No silent moves. Closing the tab with an unsaved rename asks the browser to confirm leaving instead of saving it unasked.
  • Imports and integrations are safe. Changes through import, the API or an MCP server always keep the URL.
  • Drafts stay flexible. A page that has never been published follows its name until its first publish.
  • Every language on its own. A rename in one language never moves the URL in another.
  • Parents protect their children. Renaming a category or a blog keeps the URLs of the subcategories and posts under it.
  • Tidy redirects. Chains collapse to one hop, renaming back removes the reverse redirect, and rules you added by hand are never touched.

Which module do I install?

Install Website Permalink only. Its two add-ons install themselves when they are needed:

  • Website Permalink - eCommerce adds the URL fields and rename notice to product and category forms. It installs automatically when eCommerce is installed.
  • Website Permalink - Blog adds them to blog post forms. It installs automatically when Blog is installed.

The split means a shop without a blog never has to install Blog, and the other way round.
